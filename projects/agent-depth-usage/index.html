Agent 的能力不只来自模型，也来自它拿到的工作空间、规则、技能和权限。把这些环境搭好，才算真正开始使用 Agent。
01

第 1 幕 · 理解 Agent 的工作空间

你的文件夹就是 Agent 的办公环境。桌面越清楚，它越少猜、越少浪费 token。

Agent 如何理解项目

1

工具箱

Agent 本质上在运行终端命令：看目录、读文件、搜关键词、检查差异，这些就是它的眼睛和手。

2

读取方式

文本、CSV、PDF、Word、图片各有不同读法。好 Agent 会先判断文件类型，再选工具。

3

读取优先级

不是把所有文件全读一遍，而是先看 README、任务相关文件、数据文件，再补上下文。

4

交叉关联

真正的价值在于把需求、数据、会议记录、历史输出串起来，形成能行动的项目地图。

整理工作台

推荐结构：README.md 放项目背景，TASK.md 放本次任务，data/ 放原始数据，reference/ 放参考资料，notes/ 放会议和草稿，output/ 放 Agent 产出。
02

第 2 幕 · Agent 的核心文件

README 告诉 Agent“这是什么”，AGENTS.md 告诉 Agent“在这里怎么做”。

README 与 AGENTS.md

文件主要读者适合写什么不要写什么
README.md人和 Agent项目目标、目录结构、如何运行、数据说明一次性任务细节、长篇聊天记录
AGENTS.mdAgent语言风格、操作边界、输出目录、禁区红线、项目规范只对当前一轮任务有效的临时要求

作用位置与层级

A

项目级规则

适合团队协作：同一项目下所有人和 Agent 都遵守同一套工作方式。

G

全局默认规则

适合个人偏好：比如始终用中文、输出前先说明风险、不要动敏感文件。

S

子目录规则

前端、后端、数据目录可以有不同规范。越具体的规则优先级越高。

03

第 3 幕 · 给 Agent 装上技能

Skill 是把重复纠正沉淀成可复用规则。你说三次同样的话，就该写进 Skill。

技能是什么

1

操作手册

Skill 不替代模型智力，它补的是“你这里怎么做”的细节：模板、口径、格式、流程、禁区。

2

默认值

Skill 是默认行为，不是死规矩。对话里的明确要求可以覆盖它，长期变化再改 SKILL.md。

3

触发器

description 是命中关键。要写用户真实会说的词：中文、英文、口语、命令名都可以放进去。

如何加载技能

第一个 Skill 可以这样写：先写触发场景，再写工作流程，接着写“什么时候不要做”，最后补 2-3 个正反例。流程、门禁、案例，比漂亮排版更重要。
04

第 4 幕 · Agent 自动化

自动化不是让 Agent 一直乱跑，而是给它明确触发条件、预算和停止条件。

四类自动化

类型像什么适合做什么风险
定时任务闹钟每天查邮件、每周写周报、定期生成摘要长期运行会持续消耗 token
后台任务洗衣机竞品调研、批量分析、大规模重构中途方向错会浪费一整轮
事件触发门铃新邮件分类、PR Review、报错排查触发条件写错会误运行
长期目标项目经理持续推进一个目标，分步检查直到完成必须设预算、权限和停止条件

Codex 与 Claude Code 自动化

自动化前先设三件事：预算上限、可写目录、出错时通知方式。没有边界的自动化，省下来的时间很容易被排错吃掉。
05

第 5 幕 · 从理解到实践

深度使用 Agent 的核心不是多发命令，而是会拆任务、会设检查点、会让它留下证据。

Agent 对话技巧

  • 1
    先想再做

    让 Agent 先列计划，你确认后再动手。这个习惯能避免大量返工。

  • 2
    分步下达

    一条指令里独立要求不超过 3 个，复杂任务拆成多轮，每轮有可检查输出。

  • 3
    新任务开新会话

    当任务切换、上下文混乱、对话超过很多轮时，不要舍不得旧会话。文件空间才是持久上下文。

  • 4
    设置检查点

    每完成一步停下来给你看。第二步错了只浪费两步，不会跑完十步才发现方向偏了。

派子 Agent 去干

排查、记忆、安全

第 6 幕 · 综合实践

一个长期可用的 Agent 系统，应该把任务、资料、输出、记忆和自动化边界都设计清楚。

Life OS 思路

开始前检查卡

检查项要确认的问题推荐动作
工作空间Agent 是否知道项目背景和目录结构？写 README，整理 input/output，文件名带语义。
规则哪些行为每次都要遵守？写进 AGENTS.md，不要每轮重复口头提醒。
技能哪些纠正已经重复出现三次？沉淀成 Skill，并写清触发词和反例。
自动化触发条件、预算、停止条件是否清楚？先小范围试跑，再放进长期任务。
安全会不会读到密钥、隐私或生产环境？限制权限，使用示例配置，敏感操作先人工确认。
可以直接让 Agent 帮你建第一版工作空间：
请根据我这个项目，帮我设计一个适合 Agent 协作的工作空间结构。先不要改文件，先列出 README、AGENTS.md、data、reference、notes、output 应该怎么组织，并说明哪些文件不能让 Agent 自动修改。
