AI 相关核心概念解释：模型、平台、框架、账号、API Key 等

模型

Model
AI 的"大脑"本身。GPT、Claude、DeepSeek、Gemini 这些都是模型的名字。
模型是一个经过海量数据训练出来的程序，能理解你的话、生成回答、写代码、分析文件。不同模型由不同公司训练，各有强项。你可以把它想象成不同品牌的发动机——都能提供动力，但性能和特点不同。
类比：模型 = 厨师的手艺。同一道菜，不同厨师做出来味道不同。GPT 是一位厨师，Claude 是另一位，各有拿手菜。

平台 / 厂商

Platform / Provider
训练和运营模型的公司。你要用它家的模型，就得在它家注册。
OpenAI 做了 GPT，Anthropic 做了 Claude，Google 做了 Gemini，DeepSeek 做了 DeepSeek。每家公司有自己的网站、自己的收费标准、自己的注册流程。就像不同的手机厂商——华为、苹果、小米各有各的系统和生态。
OpenAI → GPT 系列
Anthropic → Claude 系列
Google → Gemini 系列
DeepSeek → DeepSeek 系列

账号

Account
在平台上注册的身份。有账号才能用它家的东西。
跟你注册微信、注册淘宝一个道理。每个平台需要单独注册。有些平台（OpenAI、Anthropic）需要海外手机号或邮箱，这就是很多人说的"搞定海外账号"的门槛。国内平台（DeepSeek、智谱、Kimi）用手机号就能注册。

订阅

Subscription
每月交固定费用，获得使用资格。就像视频会员。
ChatGPT Plus $20/月、Claude Pro $20/月——交了月费就能在网页或 App 上使用。通常有使用量上限，超了要加钱或等下个月。这是普通用户最常见的付费方式。
类比：就像爱奇艺 / Netflix 会员。按月付费，享受服务，不续费就断。

API Key

API Key / 密钥
一串让程序代替你访问模型的"通行证"。Agent 框架用它来调用 AI。
你在网页上聊天时，平台知道你是谁（因为你登录了）。但 Agent 框架是另一个程序，它怎么告诉平台"我是替某某人来的"？答案就是 API Key——一串长长的字母数字，像一把钥匙，持有它的程序就能以你的名义调用模型。
// 这就是一个 API Key 的样子：
sk-proj-a3Bf9xK2mNpQ7rTw...

// Agent 框架用它来调用模型：
ANTHROPIC_API_KEY="sk-ant-..."
OPENAI_API_KEY="sk-proj-..."
API Key 等于你的银行卡密码。绝对不能发给别人、不能贴到公开网页上。别人拿到你的 Key 就能用你的钱调用模型。

订阅 vs API：两种付费方式

Subscription vs API billing
订阅 = 包月自助餐，API = 按量点菜。
订阅（自助餐）
每月固定 $20。在网页 / App 上聊天。有使用上限但不用操心费用波动。适合自己用。
API（按量点菜）
用多少付多少。Agent 框架通过 API Key 调用。灵活但费用不可预测。适合开发者和 Agent。
Agent 框架（Claude Code、Codex、Trae 等）大多走 API 计费或需要对应的订阅。纯网页聊天用订阅就够。

Token

Token / 令牌
AI 世界里的"计量单位"。你发的话和 AI 回的话，都按 token 数计费。
1 个英文单词约等于 1 个 token，1 个中文汉字约等于 1.5-2 个 token。当你看到"$5 / 百万 token"时，意思是处理 100 万个 token 收 5 美元。一般一次普通对话大约消耗几百到几千 token，一次复杂的 Agent 任务可能消耗几万到几十万 token。
类比：token 就像电费里的"度"。你用了多少电（token），就付多少钱。模型越贵 = 每度电单价越高。

Agent 框架

Agent Framework
给模型接上"手脚"的那层程序。有了它，AI 才能从"只会聊天"变成"能干活"。
Agent 框架负责管理任务流程（拆解目标、规划步骤、检查结果）、调用工具（读写文件、搜索网页、发邮件）、控制执行（沙箱安全、权限管理）。它本身不会"思考"——思考由模型完成——它是让模型的思考落地执行的那层"管理系统"。
类比：模型是厨师的手艺，框架是厨房。有了厨房（灶台、刀具、调料架、上菜流程），厨师的手艺才能变成一桌菜。没有厨房，厨师只能跟你聊怎么做菜。

MCP

Model Context Protocol
让 Agent 连接外部工具的"通用插头标准"。
Agent 想发邮件、查日历、读 GitHub——每个工具接口都不一样。MCP 是一个统一的连接协议，类似于 USB-C：只要工具支持 MCP，Agent 就能直接插上用，不用为每个工具单独写代码。Claude Code 支持 3000+ MCP 集成就是这个意思。
类比：MCP = USB-C 接口。以前每个工具都是不同的充电线，现在统一成一个口，什么都能插。
