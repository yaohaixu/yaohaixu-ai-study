终端新手必知的实用小知识

1
输入密码时屏幕没反应——别慌，它在记录
必知
终端里输入密码时，屏幕上不会显示任何字符——没有星号 ****，没有圆点 ●●●●，完全空白。这不是卡了，是故意的安全设计。你的输入正在被记录，打完直接按回车就行。
you@mac ~ $ sudo install something
Password: ← 你正在打字，但屏幕上什么都看不到
打错了也看不出来。如果回车后提示"密码错误"，重新输一遍就好。
2
卡住了 / 输错了？按 Ctrl + C 一键中止
救命
终端里的"万能取消键"。不管是命令输错了、程序跑飞了、还是不知道发生了什么——按 Ctrl + C 就能强制停止当前操作，回到可以输入的状态。
you@mac ~ $ npm install something
Installing... （已经跑了 5 分钟，好像卡住了）

^C ← 按了 Ctrl+C，立刻终止
you@mac ~ $ ← 回到正常状态，可以重新输入了
记住：终端里 Ctrl+C 不是"复制"，是"中止"。复制的快捷键见第 6 条。
3
按 ↑ 上箭头可以翻出之前输过的命令
实用
不用每次都重新打一遍。按 上箭头，终端会自动填入你上一条命令。连续按可以一直往前翻。找到想要的那条后直接按回车运行。
you@mac ~ $ ← 按了 ↑
you@mac ~ $ claude "帮我重构 auth 模块" ← 自动填入了上次的命令
4
按 Tab 键可以自动补全文件名和命令
实用
输到一半按 Tab，终端会自动帮你补全。输入 cd Docu 然后按 Tab，它自动变成 cd Documents/。省得你一个字一个字地打完整个文件名。
you@mac ~ $ cd Docu[Tab]
you@mac ~ $ cd Documents/ ← 自动补全了！
如果有多个匹配项，按两次 Tab 会列出所有选项让你选。
5
屏幕疯狂滚动文字——不要慌，是正常的
必知
安装软件时经常会刷出几十上百行日志，看着很吓人。这是正常的——它在告诉你正在做什么。不用逐行看，等它停下来、光标重新出现就好了。如果停在某一行不动超过 5 分钟，那才可能是卡住了（用 Ctrl+C 中止）。
Installing dependencies...
added 127 packages in 4s
added 89 packages in 2s
added 203 packages in 6s
... 几十行日志飞速滚过 ...
Done! ← 看到 Done 或光标重新出现就是完成了
you@mac ~ $
6
终端里怎么复制粘贴
必知
跟平时不太一样！因为 Ctrl+C 在终端里是"中止"，不是"复制"。
Mac
复制：Cmd + C
粘贴：Cmd + V
跟平时一样，不冲突
Windows
复制：Ctrl + Shift + C
粘贴：Ctrl + Shift + V
多按一个 Shift！或者直接右键
7
看到 (y/n) 就是在问你"是否继续"
必知
y = yes（确认），n = no（取消）。输入一个字母然后按回车。大写的那个是默认选项——比如 [Y/n] 表示直接按回车等于选了 Yes。
Do you want to continue? [Y/n] y ← 输入 y 回车，或者直接回车（Y 是默认）
8
cd 就是"打开文件夹"的意思
实用
在图形界面里你双击文件夹打开它。终端里用 cd 文件夹名 做同样的事。cd .. 是返回上一层（相当于点"返回"按钮）。
you@mac ~ $ cd Documents ← 进入 Documents 文件夹
you@mac ~/Documents $ cd my-project ← 再进入 my-project
you@mac ~/Documents/my-project $ cd .. ← 返回上一层
you@mac ~/Documents $
ls（Mac/Linux）或 dir（Windows）可以列出当前文件夹里有什么——相当于"看看这个文件夹里面的东西"。
9
看到 sudo 就是"用管理员权限运行"
必知
有些操作需要管理员权限（比如安装软件到系统目录），命令前面会加 sudo。运行后会要求输入你的电脑开机密码（输入过程看不到，参考第 1 条）。
you@mac ~ $ sudo npm install -g claude
Password: ← 输入你的电脑开机密码，看不见的
不要随意给不认识的命令加 sudo。有 sudo 的命令有权修改系统文件，用错了可能搞坏系统。只在官方教程明确要求时才用。
10
怎么退出终端 / 退出某个程序
救命
不同情况用不同方法。按优先级试：
q很多查看类程序（如 less、man）按 q 退出
Ctrl + C中止正在运行的程序
Ctrl + D退出当前终端会话
exit输入 exit 回车，关闭终端
如果以上都不管用，直接关掉终端窗口也行——不会爆炸的。
