用微信聊天和点外卖的生活场景类比 Chat AI 与 Agent 的区别

Chat AI
微信问一个很懂吃的朋友
今晚想吃意面，附近有推荐吗？
城西那家「小意思」不错！招牌是松露奶油意面，人均 80，营业到 10 点。地址是 XX 路 88 号。
能帮我点一份外卖吗？
我帮不了你点哦～你自己打开美团/饿了么搜一下吧
接下来全靠你自己：
打开外卖 App → 搜店 → 选菜 → 下单 → 付款 → 等配送
相当于：你有一个无所不知的朋友，但 ta 只能在微信里打字，不能替你动手做任何事。
Agent
跟你的私人助理对话
今晚想吃意面，帮我搞定。
正在查附近意面馆的评分和配送范围…
找到 3 家，「小意思」评分最高且能送到。选了松露奶油意面。
已下单并完成支付，订单号 #20260518。
配送中，骑手小王距你 1.2km，预计 22 分钟到。
搞定！松露奶油意面已下单，预计 8:42 送到，你等着吃就行。
相当于：同一个聪明的大脑，但这次它能打开 App、选餐、下单、付款、追踪骑手——你只管等着吃。

Chat AI 像…Agent 像…
