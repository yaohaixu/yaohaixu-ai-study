README.md任务说明书（给同学看的）说明
1
解压文件夹，在终端里进入它
把 zip 解压到电脑上，然后用 cd 命令进入文件夹
you@mac ~ $ cd Downloads/agent-demo-project
2
启动你的 Agent
用 claude、codex、hermes 等命令启动 Agent（取决于你装了哪个）
you@mac ~/agent-demo-project $ claude （或 codex / hermes）
3
把任务交给 Agent
一句话说清楚目标，Agent 会自己读所有文件、理解上下文、生成周报

  参考上周周报的格式，帮我生成本周运营周报（5/12-5/18）。

做完后想一想
  1. Agent 是不是自己把 7 个文件全部读了一遍？你有没有手动复制粘贴任何内容？
  2. 它是不是理解了文件之间的关系？比如老板问"粉丝目标完成没"——答案在 CSV 数据里，但问题在另一个文件里。
  3. 生成的周报是不是一个可以直接下载的文件，而不是一段聊天文字？
  4. 如果你用普通 ChatGPT 做同样的事，你需要手动做多少步？（打开每个文件 → 复制 → 粘贴 → 反复描述上下文 → 手动整理格式……）
  5. 这就是 Chat AI 和 Agent 的区别。
