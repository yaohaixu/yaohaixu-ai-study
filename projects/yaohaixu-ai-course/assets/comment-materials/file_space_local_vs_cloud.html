文件空间的概念，以及云端和本地的区别

文件空间：Agent 的工作台

理解这个概念，就理解了 Agent 能力的一半

什么是文件空间？
文件空间就是 Agent 能读写文件的地方——它的"办公桌"。没有文件空间的 AI 只能跟你聊天；有了文件空间，它才能真正处理你的文件、保存工作成果、在多次对话间积累上下文。

本地文件空间
文件在你自己的电脑上
文件存放位置
~/projects/my-app/
就在你电脑硬盘上的某个文件夹。你用 Finder / 资源管理器能直接看到、编辑这些文件。
Agent 怎么工作
直接读取你电脑上的文件
在你的硬盘上修改 / 创建文件
在你的电脑上运行命令
沙箱限制它只能碰工作目录
代表产品
Claude Code Codex（默认模式） OpenClaw Hermes Agent
云端文件空间
文件在远程服务器上
文件存放位置
远程容器 /workspace/
文件在云端服务器的一个隔离容器里。你看不到也摸不到，只能通过 Agent 界面操作。
Agent 怎么工作
从你的 Git 仓库拉取代码
在云端容器里安装依赖
在隔离环境中执行任务
完成后把结果推回给你

不同场景该选哪种？

数据不能离开内网，必须本地。
选本地

多人共享文件空间，云端天然适合。
选云端
